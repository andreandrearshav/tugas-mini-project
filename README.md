# Mini Project MSIB – Social Media Web Application

Mini project ini merupakan tugas dari program **MSIB (Merdeka Belajar Kampus Merdeka)**  
yang berfokus pada pengembangan aplikasi web sederhana dengan konsep
**media sosial**.

Project ini dibuat untuk melatih pemahaman dasar pengembangan web,
khususnya pada fitur autentikasi, manajemen user, dan CRUD data.

##  Deskripsi
Aplikasi web sederhana yang memiliki fitur dasar seperti sistem login,
registrasi, manajemen profil pengguna, serta interaksi antar pengguna
dalam bentuk follow dan komentar.

Aplikasi ini **bukan merupakan aplikasi media sosial lengkap**, melainkan
project pembelajaran sebagai bagian dari program MSIB.

##  Fitur
- Registrasi & Login
- Role User dan Admin
- Manajemen Profil User & Admin
- Follow & Unfollow User
- Komentar pada posting
- CRUD Data (User / Post / Komentar)
- Validasi input

##  Tech Stack
- Backend : Laravel
- Database : MySQL
- Frontend : Blade / Bootstrap
