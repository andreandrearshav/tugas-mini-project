# Mini Project MSIB – Web Application

Mini project ini merupakan tugas dari program **MSIB (Merdeka Belajar Kampus Merdeka)**  
yang bertujuan untuk melatih pemahaman dasar pengembangan aplikasi web.

## Deskripsi
Aplikasi web sederhana yang dibuat untuk mengimplementasikan konsep dasar
pengembangan web seperti CRUD, autentikasi, dan pengelolaan data.

Project ini dikembangkan sebagai bagian dari pembelajaran dan latihan mandiri.
